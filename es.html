Copia toda la página con un toque

Safari en iPhone no tiene «Seleccionar todo» para páginas web. Copiar Todo el Texto lo añade — un toque copia todo el texto legible de la página.

Ver en el App Store

Primeros pasos: activar la extensión

Solo hay que hacerlo una vez.

  1. Abre la app Ajustes en tu iPhone
  2. Ve a Aplicaciones → Safari → Extensiones
  3. Activa Copiar Todo el Texto
  4. Selecciona Permitir para todos los sitios web (la extensión solo se ejecuta cuando pulsas su botón)
Una vez activada, toca el botón de Extensiones (el botón «AA») en la barra de direcciones de Safari para abrir el popup.

1. Copiar todo el texto

Copia el texto legible de la página en Safari

Toca Copiar todo el texto en el popup para copiar todo el contenido legible de la página al portapapeles de una sola vez.

  • Muestra el recuento de caracteres y una vista previa tras copiar
  • Si tienes texto seleccionado en la página, solo se copia esa selección
  • Las páginas de más de 50.000 caracteres muestran una confirmación antes de procesarse

2. Copiar solo el artículo

Elimina anuncios, menús y pies de página — conserva el artículo

Usa Mozilla Readability para extraer solo el cuerpo del artículo. Funciona bien con artículos de noticias, entradas de blog y páginas de documentación.

  • Elimina automáticamente anuncios, navegación y elementos superfluos del pie
  • Si no se detecta el cuerpo del artículo, copia el texto completo de la página
  • La vista previa indica cuándo se ha producido este cambio

3. Seleccionar por toque

Toca regiones de la página en lugar de arrastrar controles de texto

Un enfoque diferente para la selección: toca bloques significativos de la página y copia una o varias regiones juntas.

  • Toca para seleccionar, toca de nuevo para deseleccionar — las regiones se copian en orden
  • Mantén pulsado para cambiar entre candidatos de elementos padre e hijo
  • Toca Copiar en la barra flotante para copiar todas las regiones seleccionadas
  • Al salir, todos los cambios en la página se eliminan

4. Más formatos

Abre Otros formatos en el popup para acceder a las siguientes opciones.

Copiar como Markdown

Conserva encabezados, enlaces, listas, tablas y bloques de código en formato Markdown.

Copiar para IA

Combina el artículo, el título, la URL y una instrucción en un formato listo para pegar en un chat de IA. Todo se procesa en tu dispositivo — no se envía nada.

Copia limpia

Elimina banners de cookies, botones de compartir, avisos de suscripción y texto de menú repetido mediante procesamiento basado en reglas.

Ajustes

Toca el icono de ajustes en el popup.

  • Añadir URL: elige si añadir la URL al final del texto copiado, o el título y la URL al principio (predeterminado: desactivado)
  • URL en Copiar para IA: la URL se incluye por defecto en Copiar para IA (se puede desactivar antes de copiar)

Preguntas frecuentes

No aparece el icono de la extensión

Asegúrate de que Copiar Todo el Texto está activado en Ajustes → Aplicaciones → Safari → Extensiones. Una vez activado, aparece bajo el botón de Extensiones (el botón «AA») en la barra de direcciones.

Aparece el mensaje «No se puede copiar»

La extensión no puede ejecutarse en las páginas internas de Safari (página de inicio, App Store, ajustes), el visor de PDF ni en páginas que no han terminado de cargarse.

Copiar solo el artículo devuelve muy poco texto

La detección de artículos tiene sus límites. Para páginas que no son artículos (comercio electrónico, portales, etc.), usa Copiar todo el texto o Seleccionar por toque.

El contenido detrás de un inicio de sesión no se copia

El contenido cargado de forma diferida tras el inicio de sesión, o el contenido dentro de Shadow DOM, puede no recuperarse. Copia lo que se capturó y comprueba en la vista previa qué falta.

¿Por qué es gratuita?

Es un pequeño proyecto de utilidad. No contiene anuncios, análisis, cuentas ni comunicación de red. Seguirá siendo gratuita.

¿Se guarda mi historial de navegación?

No. La extensión copia texto al portapapeles y no hace nada más. Solo tus ajustes (preferencia de añadir URL, etc.) se guardan localmente en tu dispositivo.

Nota: Dependiendo de la estructura de un sitio web o sus restricciones de acceso, es posible que no se pueda recuperar parte del texto.
