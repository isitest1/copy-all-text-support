버튼 한 번으로 페이지 텍스트를 모두 복사

iPhone의 Safari에는 웹 페이지의 '모두 선택'이 없습니다. 「전체 텍스트 복사」는 그 기능을 Safari에 추가하는 웹 확장 프로그램입니다.

App Store에서 보기

시작하기: 확장 프로그램 활성화

한 번만 설정하면 됩니다.

  1. iPhone에서 설정 앱을 엽니다
  2. 앱 → Safari → 확장 프로그램으로 이동합니다
  3. 전체 텍스트 복사를 켭니다
  4. 모든 웹사이트 허용을 선택합니다 (확장 프로그램은 버튼을 탭할 때만 실행됩니다)
활성화 후, Safari 주소창의 확장 프로그램 버튼(「AA」 버튼)을 탭하면 팝업이 열립니다.

1. 전체 텍스트 복사

Safari에서 읽을 수 있는 페이지 텍스트를 모두 복사

팝업에서 전체 텍스트 복사를 탭하면 페이지의 모든 읽기 가능한 텍스트가 한 번에 클립보드에 복사됩니다.

  • 복사 후 문자 수와 미리보기를 표시
  • 페이지에 텍스트가 선택되어 있으면 해당 선택 범위만 복사
  • 50,000자를 초과하는 경우 처리 전에 확인 메시지가 표시됩니다

2. 본문만 복사

광고·메뉴·푸터를 제거하고 기사 본문만 추출

Mozilla Readability를 사용하여 기사 본문만 추출합니다. 뉴스 기사, 블로그 포스트, 문서 페이지에 효과적입니다.

  • 광고, 내비게이션, 푸터를 자동으로 제거
  • 기사 본문을 감지하지 못한 경우 전체 페이지 복사로 대체
  • 대체가 발생했을 경우 미리보기에 표시됩니다

3. 탭으로 선택

텍스트 핸들을 드래그하는 대신 페이지 영역을 탭하여 선택

다른 방식의 선택: 페이지의 의미있는 블록을 탭하여 하나 또는 여러 영역을 함께 복사합니다.

  • 탭으로 선택, 다시 탭하면 해제 — 여러 영역이 순서대로 복사됩니다
  • 길게 눌러 상위/하위 요소 후보를 전환할 수 있습니다
  • 플로팅 바의 복사를 탭하면 선택된 모든 영역이 복사됩니다
  • 종료 시 페이지의 모든 변경사항이 제거됩니다

4. 기타 형식

팝업에서 다른 형식을 열면 다음 옵션을 사용할 수 있습니다.

Markdown으로 복사

제목, 링크, 목록, 표, 코드 블록을 Markdown 형식으로 유지합니다.

AI용 복사

기사, 제목, URL, 지시문을 AI 채팅에 붙여넣기 좋은 형식으로 결합합니다. 모든 처리는 기기에서 이루어지며 외부로 전송되지 않습니다.

클린 복사

쿠키 배너, 공유 버튼, 구독 안내, 중복 메뉴 텍스트를 규칙 기반으로 제거합니다.

설정

팝업의 설정 아이콘을 탭합니다.

  • URL 추가: 복사된 텍스트 끝에 URL을 추가하거나 맨 앞에 제목과 URL을 추가할 수 있습니다 (기본값: 꺼짐)
  • AI용 복사 URL: AI용 복사에서는 URL이 기본적으로 포함됩니다 (복사 전에 끌 수 있습니다)

자주 묻는 질문

확장 프로그램 아이콘이 표시되지 않습니다

설정 → 앱 → Safari → 확장 프로그램에서 전체 텍스트 복사가 활성화되어 있는지 확인하세요. 활성화되면 주소창의 확장 프로그램 버튼(「AA」 버튼) 아래에 표시됩니다.

「복사할 수 없습니다」 메시지가 표시됩니다

확장 프로그램은 Safari 내부 페이지(시작 페이지, App Store, 설정), PDF 뷰어, 로딩이 완료되지 않은 페이지에서는 실행할 수 없습니다.

본문만 복사가 텍스트를 거의 가져오지 못합니다

기사 감지에는 한계가 있습니다. 기사가 아닌 페이지(이커머스, 포털 등)에서는 전체 텍스트 복사나 탭으로 선택을 사용하세요.

로그인 후의 콘텐츠가 복사되지 않습니다

로그인 후 지연 로드되는 콘텐츠나 Shadow DOM 내부의 콘텐츠는 가져오지 못할 수 있습니다. 캡처된 내용을 복사하고 미리보기에서 누락된 부분을 확인하세요.

왜 무료인가요?

이것은 작은 유틸리티 프로젝트입니다. 광고, 분석, 계정, 네트워크 통신이 없습니다. 무료로 유지될 것입니다.

내 브라우징 기록이 저장되나요?

아니요. 확장 프로그램은 텍스트를 클립보드에 복사하는 것 외에는 아무것도 하지 않습니다. 설정(URL 추가 설정 등)만 기기에 로컬로 저장됩니다.

※ 웹사이트의 구조나 접근 제한에 따라 일부 텍스트를 가져오지 못할 수 있습니다.
