プライバシーポリシー / Privacy Policy

最終更新 / Last updated: 2026-08-27

日本語

「全文コピー / Copy All: Text」（以下「本アプリ」）は、利用者のプライバシーを最優先に設計されています。本アプリは完全無料であり、広告・解析SDK・アカウント登録・外部通信を一切行いません。

1. 収集するデータ

本アプリはいかなるデータも収集しません。

拡張機能は、利用者がポップアップのボタンを押したタイミングにのみ動作します。閲覧しているページのテキストは、クリップボードへの書き込みのみに使われ、端末の外へ出ることはありません。

2. 外部への通信

本アプリはネットワーク通信を一切行いません。ページの内容・閲覧URL・クリップボードの内容が外部のサーバーへ送信されることはありません。

3. 端末内への保存

設定値（URLを付加するかどうかの設定など）のみ、端末内のブラウザーローカルストレージに保存します。閲覧履歴、ページ内容、コピーしたテキストは保存しません。

4. 権限

本アプリが要求する権限は次のとおりです。

  • activeTab：ボタンを押したページのテキストを取得するために必要です。ページを開いただけで自動的に動作することはありません。
  • scripting：コンテンツスクリプトをボタン操作の起点で注入するために必要です。
  • storage：設定値を端末内に保存するために必要です。

「すべてのWebサイトへのアクセス」を常時要求する権限（<all_urls>）は使用しません。

5. 第三者サービス

本アプリは第三者のサービスを利用しません。本文抽出に使用するMozilla Readabilityは、端末内で動作するオープンソースライブラリです（Apache-2.0ライセンス）。外部への通信は行いません。

6. お子様の利用

本アプリはいかなる個人情報も収集しないため、年齢を問わず安全にご利用いただけます。

7. 本ポリシーの変更

必要に応じて本ポリシーを更新することがあります。重要な変更がある場合は本ページで告知します。

8. お問い合わせ

本ポリシーに関するご質問は、support@margheritaworks.com までご連絡ください。

English

Copy All: Text ("the App") is built with privacy as the top priority. It is completely free, with no ads, no analytics SDKs, no accounts, and no network communication of any kind.

1. Data collected

The App collects no data whatsoever.

The extension runs only when the user taps a button in the popup. Page text is used solely to write to the clipboard and never leaves the device.

2. Network communication

The App makes no network requests. Page content, browsing URLs, and clipboard contents are never sent to any external server.

3. Local storage

Only settings (such as the URL-append preference) are saved in the browser's local storage on your device. Browsing history, page content, and copied text are not stored.

4. Permissions

The App requests only these permissions:

  • activeTab: required to read the text of the page where the user pressed the button. The extension does not run automatically when a page loads.
  • scripting: required to inject the content script on demand when the user taps a button.
  • storage: required to save settings locally on your device.

The App does not request <all_urls> (persistent access to all websites).

5. Third-party services

The App uses no third-party services. Mozilla Readability, used for article extraction, is an open-source library (Apache-2.0 license) that runs entirely on your device. No data is sent externally.

6. Children

Because no personal information is collected, the App is safe for all ages.

7. Changes to this policy

We may update this policy as needed. Significant changes will be announced on this page.

8. Contact

Questions about this policy: support@margheritaworks.com.
