一键复制整页文字

iPhone 的 Safari 没有网页的「全选」功能。「全文复制」是一款 Safari 网页扩展，为您新增这项操作。

在 App Store 查看

开始使用：启用扩展

只需设置一次即可。

  1. 在 iPhone 上打开设置应用
  2. 前往应用程序 → Safari → 扩展
  3. 打开全文复制
  4. 选择允许所有网站（扩展仅在您点击按钮时运行）
启用后，点击 Safari 地址栏的扩展按钮（「AA」按钮）即可打开弹出窗口。

1. 复制全文

复制 Safari 上可读取的所有页面文字

在弹出窗口中点击复制全文，即可将页面上所有可读取的文字一次性复制到剪贴板。

  • 复制后显示字符数与预览
  • 若页面上已选中文字，则仅复制该选中内容
  • 超过 50,000 个字符时，处理前会显示确认提示

2. 仅复制正文

去除广告、菜单和页脚，仅保留文章正文

使用 Mozilla Readability 提取文章正文。适合新闻文章、博客文章和文档页面。

  • 自动去除广告、导航和页脚杂项
  • 若无法检测到文章正文，则改为复制整页文字
  • 发生改以全页复制时，预览中会显示提示

3. 点选区域

点击页面区域，而非拖拽文字控点

另一种选取方式：点击页面上有意义的区块，可同时复制一个或多个区域。

  • 点击以选取，再次点击可取消 — 多个区域按顺序复制
  • 长按可在父层与子层元素候选间切换
  • 点击浮动栏的复制，即可复制所有已选取的区域
  • 退出时所有页面变更都会还原

4. 更多格式

打开弹出窗口中的其他格式可使用以下选项。

以 Markdown 复制

以 Markdown 格式保留标题、链接、列表、表格和代码块。

复制供 AI 使用

将文章、标题、网址和指示文字整合成方便粘贴到 AI 对话的格式。所有处理都在您的设备上进行，不会发送任何数据。

清洁复制

使用规则式处理去除 Cookie 横幅、分享按钮、订阅提示和重复的菜单文字。

设置

点击弹出窗口中的设置图标。

  • 附加网址：选择是否在复制文字末尾附加网址，或在开头附加标题与网址（默认：关闭）
  • AI 复制网址：AI 复制默认包含网址（复制前可关闭）

常见问题

找不到扩展图标

请确认在设置 → 应用程序 → Safari → 扩展中已启用全文复制。启用后，图标会出现在地址栏的扩展按钮（「AA」按钮）下方。

出现「无法复制」提示

扩展无法在 Safari 内部页面（起始页、App Store、设置）、PDF 查看器或尚未加载完成的页面上运行。

仅复制正文获取的文字很少

文章检测有其限制。对于非文章页面（电商、门户网站等），请改用复制全文或点选区域。

登录后的内容无法复制

登录后延迟加载的内容，或 Shadow DOM 内部的内容，可能无法获取。请复制已捕获的内容，并在预览中查看缺少的部分。

为什么是免费的？

这是一个小型的工具型项目。没有广告、分析、账户或网络通信，且将持续免费提供。

我的浏览记录会被保存吗？

不会。扩展只会将文字复制到剪贴板，不做其他任何事。只有您的设置（网址附加偏好等）会在本地保存于您的设备中。

※ 依网站结构或访问限制，部分文字可能无法获取。
