一鍵複製整頁文字

iPhone 的 Safari 沒有網頁的「全選」功能。「全文複製」是一款 Safari 網頁擴充功能，為您新增這項操作。

在 App Store 查看

開始使用：啟用擴充功能

只需設定一次即可。

  1. 在 iPhone 上開啟設定應用程式
  2. 前往應用程式 → Safari → 擴充功能
  3. 開啟全文複製
  4. 選擇允許所有網站（擴充功能僅在您點選按鈕時執行）
啟用後，點選 Safari 網址列的擴充功能按鈕（「AA」按鈕）即可開啟彈出視窗。

1. 複製全文

複製 Safari 上可讀取的所有頁面文字

在彈出視窗中點選複製全文，即可將頁面上所有可讀取的文字一次性複製到剪貼簿。

  • 複製後顯示字元數與預覽
  • 若頁面上已選取文字，則僅複製該選取範圍
  • 超過 50,000 個字元時，處理前會顯示確認訊息

2. 僅複製正文

去除廣告、選單和頁尾，僅保留文章正文

使用 Mozilla Readability 提取文章正文。適合新聞文章、部落格文章和說明文件頁面。

  • 自動去除廣告、導覽列和頁尾雜項
  • 若無法偵測到文章正文，則改為複製整頁文字
  • 發生改以全頁複製時，預覽中會顯示提示

3. 點選區域

點選頁面區域，而非拖曳文字控點

另一種選取方式：點選頁面上有意義的區塊，可同時複製一個或多個區域。

  • 點選以選取，再次點選可取消 — 多個區域依序複製
  • 長按可在上層與子層元素候選間切換
  • 點選浮動列的複製，即可複製所有已選取的區域
  • 退出時所有頁面變更都會還原

4. 更多格式

開啟彈出視窗中的其他格式可使用以下選項。

以 Markdown 複製

以 Markdown 格式保留標題、連結、清單、表格和程式碼區塊。

複製供 AI 使用

將文章、標題、網址和指示文字整合成方便貼入 AI 對話的格式。所有處理都在您的裝置上進行，不會傳送任何資料。

清潔複製

使用規則式處理去除 Cookie 橫幅、分享按鈕、訂閱提示和重複的選單文字。

設定

點選彈出視窗中的設定圖示。

  • 附加網址：選擇是否在複製文字末尾附加網址，或在開頭附加標題與網址（預設：關閉）
  • AI 複製網址：AI 複製預設包含網址（複製前可關閉）

常見問題

找不到擴充功能圖示

請確認在設定 → 應用程式 → Safari → 擴充功能中已啟用全文複製。啟用後，圖示會出現在網址列的擴充功能按鈕（「AA」按鈕）下方。

出現「無法複製」訊息

擴充功能無法在 Safari 內部頁面（起始頁、App Store、設定）、PDF 檢視器或尚未載入完成的頁面上執行。

僅複製正文取得的文字很少

文章偵測有其限制。對於非文章頁面（電子商務、入口網站等），請改用複製全文或點選區域。

登入後的內容無法複製

登入後延遲載入的內容，或 Shadow DOM 內部的內容，可能無法取得。請複製已擷取的內容，並在預覽中查看缺少的部分。

為什麼是免費的？

這是一個小型的工具型專案。沒有廣告、分析、帳戶或網路通訊，且將持續免費提供。

我的瀏覽紀錄會被儲存嗎？

不會。擴充功能只會將文字複製到剪貼簿，不做其他任何事。只有您的設定（URL 附加偏好等）會在本機上儲存於您的裝置中。

※ 依網站結構或存取限制，部分文字可能無法取得。
